# Blendaroo has moved

Blendaroo is now **Sound by Sound**, at https://soundbysound.app (source: https://github.com/zanarmstrong/blendaroo).

This repo only keeps the old address, blendaroo.zanarmstrong.com, working: its page forwards each visitor to the new
address with everything the old app saved in their browser (words read, aliens, settings, lesson lists), so nobody
loses their progress. Old links (lessons, list links, progress and backup links) keep working.

- `index.html` (and the same `404.html`): the forwarding page
- `sw.js`: removes the old app's offline copy
- `CNAME`: blendaroo.zanarmstrong.com
